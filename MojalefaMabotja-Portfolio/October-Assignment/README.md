## Project: PowerShare

PowerShare is a project focused on providing access to portable power solutions through a rental platform. The concept addresses the challenges that electricity interruptions create for small businesses and informal traders.

The platform aims to help businesses access portable power equipment to support their daily operations.

My portfolio documents the Agile planning and development activities associated with the project.
