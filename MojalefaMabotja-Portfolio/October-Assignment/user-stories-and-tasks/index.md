# PowerShare: User Stories and Tasks

## 1. Introduction

PowerShare is a portable power station rental platform designed to help micro-entrepreneurs and informal traders access temporary power during load shedding.

This document presents the user stories and associated tasks for the development of PowerShare. Each card contains one user story and three tasks, following the format used on the project's Trello board.

As the Full-Stack Developer, my responsibilities include frontend and backend development, API integration, database interaction, and application testing.
